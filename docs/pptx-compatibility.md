# 性能版 PPTX 兼容导出

更新：2026-10-19。适用版本：0.6.3-performance.1；Windows 编译验证，并在本机 PowerPoint 抽查实际 72 页文件的第 1、2、5 页及一页合成 PSD／WebP／损坏图片样例。未进行 WPS、全量页面或动画验证。

PPTX 导出采用可移植图片策略，目标是让接收方不依赖本机的 PSD 和外部图片路径。它不是完整的 Office 兼容认证，也不支持旧二进制 `.ppt` 格式。

| 内容 | 导出行为 |
|---|---|
| 可解码的 PNG、JPEG、GIF | 验证后保留原始图片字节，内嵌到 PPTX；保留 GIF 帧，接收端是否播放取决于其支持 |
| 支持的 PSD 合成图、WebP、BMP、TIFF | 转为内嵌 RGBA PNG；保留解码得到的透明度和像素尺寸，不使用编辑／放映低清代理 |
| 可解码的 EMF／WMF | 保留原始矢量字节并内嵌；PowerPoint 原生渲染，避免将 DeckCraft 字体替换与栅格化差异固化到文件 |
| 外链图片 | 优先打包当前已接受的内存画面；没有缓存时尝试读取本地绝对路径或 file URI。导出不联网、不自动刷新已载入图片 |
| 图片损坏、缺失、不支持或超过安全上限 | 原位置显示中文提示框；图片背景、填充、母版、版式和对象预览也使用可见提示图片；图片项目符号失败时改为警告符号 |
| 无法保留、且没有可用预览的未知对象 | 导出为中文提示框；可安全保留的无外部关系 XML 仍保留，有可用预览则导出静态预览 |
| 音视频媒体条目缺失 | 原位置显示提示框；正常音视频及其现有导出行为保留，无封面不当作媒体损坏 |

提示框不会继承失败图片的裁剪、透明度或调色，避免提示也被隐藏。普通图片和未知对象的提示为可编辑文本形状；背景、填充中的提示为 PNG。对象的层级、位置、旋转和隐藏状态沿用原设置。编辑画面、缩略图和普通渲染路径中的图片解码失败、没有预览的未知对象也会显示提示。

## 使用方式

继续保留 `.deckcraft` 工作文件，它保存 PSD 原始数据或外链与哈希。对外另存一份 `.pptx`。导出操作不会修改内存中的工作文档，但重新打开导出的 PPTX 后，PSD／外链已是兼容图片，不再具有原 PSD 图层或文件自动刷新关系。

如果刚在源图编辑器保存过修改，先点击图片刷新，确认画面后再导出。链接已断开但内存仍有可用画面时，导出当前画面；没有可用数据时才显示提示。刷新失败保留旧画面的现有行为不变。没有基准目录的相对路径、未载入的网络链接不能自动读取。

## 限制

字体后续改进（2026-10-18）：新增 [字体检查器与自动嵌入](font-embedding.md)，修复中文字体名匹配。
本地第 2 页中文粗体和字宽明显改善；缺失的自定义字体、可变字体嵌入与部分渲染差异仍有限制。

- PSD 仍限 RGB／灰度、8／16 位的合成图；CMYK、Lab、索引色、32 位、PSB、ICC 色彩转换不支持。转换后的 PNG 是静态合成图片。
- SVG 渲染尚未实现，独立 SVG 会显示提示；从 PPTX 导入时已有 PNG 预览的对象可以使用预览。
- WebP 动画、多页 TIFF 仅取当前解码器的静态画面。EMF／WMF 在 DeckCraft 中仍使用自身渲染器显示，和 PowerPoint 的画面可能有字体与绘图差异。
- 普通栅格图片在解码前检查 RGBA 像素预算（256 MiB），解码器分配预算同为 256 MiB；源字节上限 512 MiB。这些是单项限制，不是导出总内存上限。
- 字体替换、复杂动画、特殊效果、OLE／SmartArt 可编辑性、音视频编码和外链音视频仍需接收端验证。本次不会识别所有跨软件差异，也不会将正常对象一律覆盖成提示。
- 图片兼容转换会增加保存时的解码和压缩工作，转换后的文件大小也可能变化；不是性能加速缓存。
- 实测中 DeckCraft 预览的中文粗体、字宽和部分阴影与 PowerPoint 不一致；抽查的原生文字在导出后用 PowerPoint 打开仍保留原有样式。编辑预览还需单独修正。
