# 字体打包与检查器

状态：性能版 0.6.3-performance.1，2026-10-19。

入口：开始 → Multi-Function（多功能）→ 字体检查器。窗口可调整大小，字体列表独立滚动；
后台扫描当前文稿，修改后提示重新检查。显示字体族和样式、所在页、当前解析字体、缺失字形、
模拟粗体/斜体、已嵌入状态与未打包原因。主题、母版、版式、备注、表格与项目符号也纳入清单。
这是诊断清单，不会自动替换文稿内容。未使用的主题脚本字体不会全部复制进文件。

新文稿与没有明确关闭字体嵌入的文件默认启用“保存时自动打包允许编辑嵌入的字体”。
该开关跟随文稿保存，可撤销；关闭后不再添加字体，原有嵌入数据仍保留。
保存 `.deckcraft` 和 `.pptx` 均在工作文档的快照中添加字体，不修改当前编辑状态。
检查器中的“下次保存时自动打包”是保存计划；重新打开保存副本后显示“已嵌入”。

## 支持范围

- 读取字体 OS/2 的 `fsType` 文档嵌入标志。允许安装嵌入或编辑嵌入的静态 TrueType 字体默认打包。
- TTC 集合抽取所需字体面，重写表偏移和校验和。保存完整字库，尊重禁止子集化标志。
- PPTX 写入 `p:embeddedFontLst`，按 regular、bold、italic、boldItalic 建立关系，字体部件为未压缩 EOT。
- `.deckcraft` 使用带样式的字体记录与媒体字节，兼容旧版 family/media 记录。
- 重新打开时，正文、中文/复杂文字槽位和符号字体优先查找该文稿的嵌入字体。
  不安装字体、不加入全局字体列表，不影响其他文稿；EMF/WMF 内部文字仍使用其现有字体路径。
- 字体索引支持文件 name 表中的本地化字体名，例如“微软雅黑”“等线”，避免已安装字体被误判缺失。

## 限制

- 字体禁止嵌入、仅允许预览/打印、仅允许位图嵌入、权限未知时不自动复制。字体许可证仍然适用。
  文档嵌入与把字体随软件分发不同，本功能不向安装包或仓库添加系统字体。
- 可变字体、CFF/OTF 字体的 Office 嵌入转换暂不支持。单个源字体不超过 40 MiB，
  单次保存新增字体的源字节预算为 256 MiB，超出会在检查器中提示。
- 缺失字体无法打包；模拟粗体/斜体和字形回退不等于已有原字体。不改写原文稿中的字体名称。
- 未压缩 EOT 1.0 / 2.1 可供当前渲染器读取。其他压缩、混淆或带站点限制的 EOT 字体部件保留回写，
  检查器显示无法解析，渲染使用本机字体/回退。不承诺所有第三方嵌入变体兼容。
- 完整中文字体可能显著增大文件。未使用的既有嵌入字体不会被自动清理。
- WPS、不同版本 Office 的跨机效果、复杂脚本及全部页面没有完整验证。

标准参考：[OpenType OS/2 fsType](https://learn.microsoft.com/en-us/typography/opentype/spec/os2#fstype)、
[W3C EOT 格式](https://www.w3.org/submissions/EOT/)、ECMA-376 PresentationML `embeddedFontLst`。

验证：字体权限、TTC 校验和、EOT 截断输入与完整字库回读、PPTX 字体关系和二次保存、
文稿字体隔离、自动打包开关与幂等性测试通过。Windows 调试构建通过。
本地实际文稿发现中文字体名称匹配问题，以及确实缺失的自定义字体；第 2 页修复后的粗细和字宽明显改善。
PPTX 75 项测试和 WebAssembly 检查通过。新增字体嵌入的 PowerPoint 打开实测未完成：
本机 UI 自动操作未能可靠填写文件对话框，不能把包结构/回读测试视为跨软件验证。

界面更新（2026-10-18）：检查器采用字体列表与选中项详情，支持名称搜索和“仅看需注意项”。
使用页码可点击，跳到对应幻灯片并收起检查器；再次打开保留选中字体和筛选。
文稿修改后须重新检查再跳转，避免页面增删或重排后使用旧页码。界面和跳转已在 Windows 调试版验证。
